Sobre GG Radar

GG Radar busca responder una pregunta sencilla: ¿qué ha cambiado desde la última vez que jugué y qué significa para mi cuenta?

El proyecto combina cambios de balance estructurados, herramientas de progresión y, cuando la conexión con la API oficial esté terminada, análisis a partir de Player Tags públicos.

Independencia

GG Radar es un proyecto de fans independiente. No es oficial, no está respaldado por Supercell y no pretende hacerse pasar por un producto de Supercell.

Criterio de las recomendaciones

Las prioridades de mejora de GG Radar son heurísticas: combinan nivel actual, trofeos, coste restante y cambios recientes. No son una tier list oficial ni garantizan rendimiento competitivo.

Fuentes

Los cambios de balance enlazan, cuando corresponde, a fuentes públicas oficiales de Supercell. Los datos de cuenta se obtendrán mediante la API oficial de Brawl Stars cuando la conexión de producción esté activada.
