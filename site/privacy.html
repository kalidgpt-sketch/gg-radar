GG Radar

Política de privacidad

Última actualización: 24 de septiembre de 2026.

GG Radar es una herramienta independiente para jugadores. Actualmente no exige crear una cuenta de usuario ni solicita datos personales para utilizar sus funciones públicas.

Player Tags

Cuando se active la consulta de Player Tags reales, GG Radar enviará el identificador introducido al backend de GG Radar para solicitar datos públicos del perfil mediante la API oficial de Brawl Stars. El backend utiliza una caché temporal en memoria para reducir consultas repetidas y no está diseñado para crear perfiles personales persistentes a partir de esos Player Tags.

Registros técnicos

El proveedor de alojamiento puede procesar datos técnicos necesarios para prestar y proteger el servicio, como direcciones IP, fecha y hora de las solicitudes o información básica del navegador.

Publicidad y analítica

En este momento GG Radar no tiene publicidad de Google AdSense activada. Antes de activar servicios publicitarios o de analítica que utilicen cookies o tecnologías similares, esta política se actualizará y se implantará el mecanismo de consentimiento correspondiente cuando sea necesario.

Terceros

GG Radar utiliza infraestructura de GitHub Pages y Fly.io. Los enlaces a Supercell u otros sitios externos están sujetos a las políticas de privacidad de esos servicios.

Cambios

Esta política podrá actualizarse a medida que GG Radar incorpore nuevas funciones. La fecha de la parte superior indicará la revisión más reciente.
